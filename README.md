# Asafo Print POS 🖨️💰

A simple, fast, offline-first price calculator for print shops, developed from over 10 years of hands-on experience in the design and print industry!

## About This Project

Hi! I'm **Godwin Appiah**, founder of **Nenifix**. After working in design and print for over a decade, I built this tool to help print shops calculate prices quickly and accurately, increasing productivity every day!

## Features

✅ **100% Offline** - Works without any internet connection!  
✅ **Material Management** - Add, edit, and delete your own materials and rates!  
✅ **Beautiful UI** - Clean, modern interface designed for busy print shops!  
✅ **Multiple Versions** - Web, Android, and Windows (Electron) versions available!  
✅ **Local Storage** - All your materials and settings are saved locally!  

## How to Use (Web Version)

1. **Calculator Tab**: Enter height, length, and select material → Click "Calculate" to see the price!
2. **Manage Materials Tab**: 
   - Add new materials with custom rates
   - Edit existing materials
   - Delete materials you don't need

## Versions Available

### 🌐 Web Version
- Node.js + Express backend
- Works in any modern browser
- Access at http://localhost:3000

### 📱 Android Version (Capacitor)
- Build an APK for Android 10+
- Full offline functionality

### 🪟 Windows Version (Electron)
- Native Windows desktop app
- No browser needed
- Build your own .exe
